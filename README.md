## 1. Site Can't Be Reached, Network Mismatch
```TXT
This site can’t be reached
nexomia.win’s DNS address could not be found. Diagnosing the problem.
DNS_PROBE_POSSIBLE
```
**The Solution is:**
1. Download [1.1.1.1](https://one.one.one.one/) Installer
2. Run the installer as admin (press yes when prompted)
3. When given two options, make sure pick **LEFT SIDE** or **Private Browsing**
4. Change the mode to **DNS only (HTTPS)**
5. Connect

## 3. How to Exclude Nexomia from Windows Defender?
**Option 1 (Recommended)**
1. Open your Nexomia.exe
2. Click Editor, Welcome Tab
3. Press **Exclude from Defender** (Require Administrator Privilege)
4. Press OK if prompted

**Option 2**

Nexomia folder located at `%appdata%\win.nexomia`

**MAKE SURE NEXOMIA IS IN A FOLDER BEFORE YOU DO THIS**
1. Search "Windows Security" in search bar
2. Go to "Virus & threat protection"
3. go to "manage settings" under "Virus & threat protection settings"
4. scroll down until you see "exclusions"
5. click "Add an Exclusion"
6. Click on "Folder"
7. Make sure to choose the folder where Nexomia is located
8. Nexomia should now be excluded from defender.

## 5. Your Browser flags Nexomia.exe as Unsafe software
```
Download Nexomia.exe Denied, Virus Detected
```

**The Solution is:**
1. Click the three dots in Any Browser and select Settings > Privacy and security > Security.
2. Under Safe Browsing, select No protection (not recommended).
3. Download the file, then immediately switch back to Standard protection.

## 7. Cannot Succeed Opera ADS in work.ink?
**Option 1**
1. Click **Learn More** on the Opera offer
2. Click **Install** button (dont run the installer)
3. **Immediately** switch to another tab (make sure its the browser tab & not alt tab)
4. Wait **30-50 seconds**
5. Come back to your work.ink tab **After** 30-50 seconds (the time is random btw)
6. Click **Install** button again (dont run the installer)
7. **Immediately** switch to the tab again (make sure its the browser tab & not alt tab)
8. Wait **1-2 minutes**
9. Come back to your work.ink tab again **After** 1-2 minutes (the time is random btw)

*The tab runs in the background and so you don't have to install anything.*

**Option 2**
1. Use your phone to complete work.ink
2. Send the file to ur Computer.

## 10. Cannot Download Resources.
**LUAU-LSP**
```
Error: Process cannot get access to the file because the file is busy with another process (os error 32)
```

**The Solution is:**
1. Press Windows + R
2. Type `cmd` and press RUN
3. Type `taskkill /im luau-lsp.exe /f /t`
4. Install Luau LSP again

**VPN**
```
Can't reach the download server. If this keeps happening, try a VPN like Cloudflare WARP or another one, your ISP or region may be blocking the request. 
```

**The Solution is:**
1. Download [1.1.1.1](https://one.one.one.one/) Installer
2. Run the installer as admin (press yes when prompted)
3. When given two options, make sure pick **LEFT SIDE** or **Private Browsing**
4. Change the mode to **Traffic and DNS (TLS)**
5. Connect
